我是一家公司的老闆，下面是我公司的資料（Excel／CSV 內容：顧客、庫存、訂單、送貨車、營收）。
請你先幫我整理成結構化資料：
1. 依類型分組，輸出成一份乾淨的 JSON（顧客、庫存、訂單、送貨車、營收各一組）。
2. 每一組都算出幾個關鍵數字（例如顧客人數、庫存總量與缺貨品項、訂單狀態分布、營收合計）。
3. 最後用三行白話告訴我，這家公司現在最值得注意的事。
先不要畫任何東西，只整理資料。

我的資料如下：
（把你的資料貼在這裡）

示範資料請用 sample_data.csv，打開、全選、貼在「我的資料如下：」後面。想換成自己公司的，貼你自己的 Excel／CSV 內容就行。

【第二段：Design a 3D world（設計 3D 小鎮）】
很好。現在請把剛剛整理好的資料，設計成一座 3D 小鎮的「設計稿」，先不要寫程式：
1. 視角與風格：等角視角（像模型玩具的斜上方俯瞰）、粉彩色系、所有建築與道具都圓潤、小巧、乾淨，背景是柔和的淡色漸層。
2. 資料對應：倉庫＝庫存（建築大小或貨架高度代表庫存量，缺貨的做成紅色提醒）；民宅＝顧客（一棟代表一位顧客，常客的屋子大一點）；辦公塔＝營收（塔的高度代表金額）；送貨車＝送貨車（在路上來回開）。
3. 光影：暖色主光從左前上方斜照，影子柔和而長；冷色補光從右側；窗戶和路燈會發光。
4. 質感：同一棟建築的頂面最亮、受光面中等、背光面最暗；每棟建築一個主色，加一個深一階的結構色；要有窗框、屋簷、門這類小結構，不要光禿禿的方塊。
5. 細節：路燈、樹、灌木、長椅、小鳥、煙囪冒煙，到處有一點小東西在動。
6. 互動：每個可點的東西，點下去要跳出一張數字卡，寫出它背後的資料。
請列出每個物件的位置、顏色、大小要代表哪個數字，以及數字卡要顯示的文字。

【第三段：Build it with Three.js（做成網頁）】
很好，照這份設計稿，用 Three.js 把它做出來。要求：
1. 只做成一個 HTML 檔，所有程式與資料都寫在裡面，存起來用瀏覽器直接打開就能跑，不需要安裝任何東西。
2. Three.js 用 CDN 載入（import map 指到 three@0.160 的 module 版）。
3. 等角（正交）相機；滑鼠拖曳可以轉動視角、滾輪可以縮放；手機也能用手指轉。
4. 建築、樹、路燈要有陰影；打開柔和陰影。窗戶與路燈用自發光材質。
5. 送貨車在路上來回開，小鳥繞圈飛，煙囪冒煙；動畫只用時間算，不要卡頓。
6. 點任何建築或送貨車，旁邊跳出一張圓角數字卡，顯示它背後的資料（資料直接用上一步整理好的數字）；再點一下空白處把卡收起來。
7. 畫面上方放一行標題，寫出公司名稱和本月營收。
請直接把完整的 HTML 程式碼放在一個 ```html 程式碼區塊裡給我，區塊外只用一兩句話說明。

【怎麼打開】
把第三段回覆裡 html 區塊的內容複製出來，存成 .html 檔，用瀏覽器（Chrome／Edge）打開。需要連網（Three.js 從 CDN 載入）。
