# 5 製作

照規格把畫面做出來，保持每一層都能單獨修改。

**這一步要產出：** 可預覽的 composition

## 要做

- [ ] **5.1 版面**：滿版優先，留白要有目的；照片先轉正、保持比例；直式短片底部約 300 px 和右側會被平台介面蓋住
  - 滿版優先，留白要有目的（S5-18）
  - 口播特效的擺位規則：人後字只放沒被擋的地方，卡片避開臉和字幕（S5-27，待試）
  - 保留可編輯的中間層（S5-01）
  - 人物永遠在最上層，圖卡不可蓋臉（S5-02）
  - 口播片的版面與推近數字（S5-03，待試）
  - 視訊錄影放半屏或遮罩，臉不要太大（S5-19）
- [ ] **5.2 動效**：照規格移植：時長、緩動、距離照抄，只換內容和顏色
  - 移植動效時時長、緩動、距離照抄，只換文字、顏色、素材（S5-06，待試）
  - Remotion 短片三段提示詞：建專案、照秒數出畫面、自己看自己聽（S5-31，待試）
  - 網站動效的三條底線（S5-07，待試）
  - 一個主編輯器，特效另外算成片段再放回去（S5-25，待試）
  - 照片慢移只在引導注意時用；微推約 10 秒 100%→105%（S5-33，待試）
- [ ] **5.3 字幕**：依角色（數字、問句、條件、重點、一般）設計樣式和位置
  - 字幕依角色設計，不用一個固定的高亮框（S5-17）
  - 字幕和畫面大字的規則：一字不差、每行 11 字內、大字用口白原詞（S5-26，待試）
  - 檢查：自動字幕一定要邊聽邊讀校對（S5-35）
  - 語音辨識對時間點，失敗時改用音量分段（S5-11）
  - 效果要出現在念到那個字的那一格，不是念完才出現（S5-22）
  - 大字在頭後面：圖層順序、字的大小位置、進場和前景字幕都有數字（S5-32，待試）
- [ ] **5.4 去背**：只在需要「字在人後面」的段落用
- [ ] **5.5 轉場**：轉場是標點，不是每鏡都加；直接切也是選項
- [ ] **5.6 數字與圖表**：數字直接標在圖上，圖表用滿垂直空間
  - 用 Claude 把主題畫成圖解：先選版型，再加三句固定要求（S5-30，待試）

## 用什麼工具

- **ffmpeg-skill**（T-03）：剪、接、轉檔、音量、平台規格檢查（check.py）、縮圖表（look.py）
- **stable-ts**（T-05）：已經有定稿文字時，把文字強制對齊到聲音，產生逐字時間
- **rembg（U2-Net／BiRefNet）**（T-13）：非 Mac 平台的去背；邊緣品質看模型
- **HyperFrames**（T-19）：主要的影片引擎：用 HTML、CSS、GSAP 做畫面，逐格算成影片；snapshot 指令可以取任意時間點的定格。同一套生態的技能：hyperframes-cli 管指令操作（建專案、預覽、算圖）；hyperframes-registry 有約 450 個現成轉場和字卡，第 5 階段先從這裡挑，不從零寫
- **lemo-opuscar**（T-21）：需要現成的影片風格（59 種，含水彩、衛星簡報等）和它的風格提示詞
- **diagram-design**（T-31）：需要流程圖、架構圖、比較圖這類圖表（45 種，輸出 HTML＋SVG，可套品牌配色）
- **taste-skill（design-taste-frontend）**（T-32）：網頁的美術方向：抽選研究過的方向、用開放圖庫真圖、三種寬度檢查
- **Apple Vision 人物分割**（T-35）：Mac 上的人物去背（預設）：免費、不用下載模型、邊緣細
- **Motion Prompt**（T-36）：指定和移植動效：168 個有編號的動作，附規格和 Canvas 程式；photo 包只當生圖用語
- **faster-whisper／mlx-whisper**（T-56）：語音轉文字和逐字時間；Mac 用 mlx-whisper 較快。要直接輸出繁體加標點時用（P12：字錯率 3.8%／13.4%，比 Paraformer 慢 4–6 倍）
- **GSAP AI Skills（官方）**（T-82）：在 HyperFrames（底層是 GSAP）裡寫時間軸、文字拆分、SVG 變形動效時
- **emilkowalski/skills（animate、choreograph 等）**（T-90）：做 HTML 動效（HyperFrames）要選曲線、時長、編排時
- **sherpa-onnx**（T-95）：需要本機離線語音辨識和逐字時間戳時。講者分辨預設（P13：pyannote-segmentation-3.0＋3D-Speaker，46 MB，兩人對談正確率 92.7%、自動判斷講者數）
- **SenseVoice（SenseVoiceSmall）**（T-102）：中文為主的逐字稿：中、粵、英、日、韓；要快、要標出笑聲掌聲等聲音事件時。保留給多語自動辨識、情緒與聲音事件標籤；一定要配 fsmn-vad，否則遇停頓就截斷（P12）
- **FunASR（modelscope）**（T-103）：中文逐字稿要一次做完語音偵測、加標點、講者分辨時。中文逐字稿預設（P12：字錯率 0.8%／12.6%，最快）；輸出簡體無標點，用 OpenCC 轉繁、標點另外處理；講者分辨用 T-95，不用 CAM++（要 1.1 GB 標點模型）
- **HandDraw-Skill**（T-124）：要做白板手繪解說片（逐筆畫出 SVG＋字）時
- Mac 內建 Apple Vision 人物分割（S5-13）

**這一步可以試的新工具：**
- Remotion（T-24，待試）：想用 React 寫影片時；超過 3 人的公司要付費；複查條件：下一次 HyperFrames 做不到的效果時；個人用戶免費；改用公司名義、員工超過 3 人或年營收超過 100 萬美元時要重新確認
  - 測試方法：何時：HyperFrames 做不到或很難做的鏡頭｜怎麼做：同一個鏡頭用 Remotion 做一次，跟 HyperFrames 版比｜看什麼：完成時間、修改次數、算圖時間、檔案能否接回現有流程｜有效＝明顯比 HyperFrames 省事，且能接回現有剪輯流程
- Pixel2Motion（T-83，待試）：要把點陣圖 logo 做成片頭或網頁的 logo 動畫時；複查條件：有 logo 動畫需求時
  - 測試方法：何時：要做 logo 動畫｜怎麼做：把一個點陣 logo 轉 SVG 並做開場動畫｜看什麼：SVG 跟原圖疊合程度、動畫品質｜有效＝形狀沒跑掉且負責人核准
- story-to-handdrawn-video（T-84，待試）：要把中文故事或一組圖片做成手繪日記漫畫風的直式動畫時；複查條件：要做手繪風故事片、並接好生圖工具時（repo 628 MB）
  - 測試方法：何時：下一支故事型短片｜怎麼做：用 5 張現成圖片和一段故事做一支預覽版｜看什麼：手寫中文字是否正確、轉場、算圖時間、能否接配音｜有效＝預覽版可直接配音使用，中文字沒有錯
- FunClip（T-87，待試）：要從長片轉字幕、讓 LLM 挑片段剪成短片時；複查條件：有中文口播樣本時（中文模型約 1 GB）
  - 測試方法：何時：有長片要切短片｜怎麼做：拿一支長片讓它挑 3 段｜看什麼：挑的段落是否能獨立成立、字幕準確度｜有效＝至少 2 段直接可用
- parakeet-mlx（T-104，待試）：英文或歐洲語言的逐字稿要在 Apple Silicon 上跑得很快時；複查條件：下一支英文口播要逐字稿時
  - 測試方法：何時：桌上試驗｜怎麼做：同一段英文口播和 faster-whisper 各轉一次｜看什麼：字錯率、逐字時間、速度｜有效＝字錯率不高於 faster-whisper 且快 2 倍以上
- whisper.cpp（T-105，待試）：不想裝 Python、要在命令列或其他程式裡直接跑 Whisper 時；複查條件：需要不靠 Python 的轉錄時
  - 測試方法：何時：桌上試驗｜怎麼做：同一段口播和 faster-whisper 各轉一次｜看什麼：字錯率、速度、記憶體｜有效＝結果相同且不需 Python 環境
- Instagram Edits（Mac 版）（T-126，待試）：要在 Mac 上剪 Reels、直接發佈或發試用 Reels 時；複查條件：負責人照檢查表試完回報時
  - 測試方法：何時：下一支要發的 Reels｜怎麼做：照 bench/runs/intake/2026-11-15/edits_checklist.md 的 7 項試｜看什麼：多軌、關鍵幀、字幕、安全區提示、匯出有無浮水印、試用 Reels｜有效＝能取代手機剪輯又不加浮水印

## 要注意

- 停頓後的逐字時間會飄（S5-16）
- 底部約 300 px 會被平台介面蓋住（S5-20）
- 疊在實拍上的標示，要在鏡頭頭、中、尾確認位置（S5-21）
- 中文字型要指定，找不到就停下，不要讓程式自己換字型（S5-24）
- 分割畫面只在多一格能改變理解時才加（S5-34，待試）
