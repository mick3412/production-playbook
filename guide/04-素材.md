# 4 素材

把畫面、聲音、字型備齊，而且每一樣都能合法使用。

**這一步要產出：** 素材清單＋授權表

## 要做

- [ ] **4.1 實拍與圖庫**：挑素材前先看過畫面，確認內容和比例；大檔用可續傳下載並驗證完整，前處理後逐段比對長度
  - 真截圖勝過模擬畫面（S4-04，待試）
  - 檢查：照片先轉正，再檢查比例（S4-13）
  - 檢查：前處理後逐段比對片段長度，不足就補最後一格（S4-17）
  - 先規劃每段特效，再錄影；錄的時候頭頂和左右留空間（S4-18，待試）
- [ ] **4.2 生成素材**：生圖、生影片的提示詞；同一角色或場景用固定參考圖
  - 寫具體的光影、質感、細節清單（S4-05，待試）
  - 首尾幀釘住產品圖，避免失真（S4-06，待試）
  - 長片一致性靠參考圖和狀態表（S4-07，待試）
- [ ] **4.3 定稿配音**：依核准稿逐句生成定稿配音，依實際聲音裁切；第 3 階段的暫配要換掉
  - 配音每句分開生成（S4-15）
- [ ] **4.4 配樂與音效**：找可商用的來源，記下作者和授權
  - AI 配樂的風格用英文寫曲風、樂器、情緒，最後加 no vocals（S4-20，待試）
  - 音效先找真人錄音，找不到再用程式生，最後統一對位（S4-22，待試）
- [ ] **4.5 授權登記**：每個素材記來源、授權、是否需要標註
  - 沿用 MIT 程式碼要保留授權註解（S4-10，待試）
- [ ] **4.6 口播粗剪**：真人錄影先剪氣口和停頓，同一句只留最後一個 take，故意留的停頓先標出來
  - 依逐字時間剪停頓，不剪進字裡（S4-12，待試）

## 用什麼工具

- **auto-editor**（T-01）：口播粗剪第一步：依音量剪掉停頓和空白；故意留的停頓要先排除
- **LosslessCut**（T-02）：手動挑素材、切長錄影，不重新編碼
- **DeepFilterNet**（T-09）：視訊或手機錄音的底噪
- **Demucs**（T-10）：素材混著背景音樂時，抽出乾淨的人聲
- **Kokoro TTS**（T-55）：免費、本機、沒有額度限制的英文配音；每句分開生成，時間精準（數字要先拼成英文字）
- **Pixabay（影片與照片）**（T-57）：免費、可商用的實拍 B-roll；挑之前先看畫面，記下影片 ID
- **Poly Haven**（T-58）：3D 場景用的材質、HDRI 和模型
- **Kevin MacLeod（incompetech）**（T-59）：免費配樂；CC BY 4.0，說明欄一定要附標註

**這一步可以試的新工具：**
- resemble-enhance（T-11，待試）：降噪後音質還是很差，需要增強時；複查條件：DeepFilterNet 處理不了的錄音出現時
- ClearerVoice-Studio（T-12，待試）：多人對談只要抽出其中一位講者時；複查條件：做多人對談片時
- FILM（T-18，未採用）：實拍素材需要補幀做慢動作時；複查條件：需要慢動作 B-roll 時
- OpenCreator（原 KrillinAI）（T-26，未採用）：需要影片翻譯和多語配音時（以 Codex 為引擎，要 OpenAI 付費帳號）；複查條件：做雙語版本時，再找能接免費本機模型的工具
- Pocket TTS（Kyutai）（T-46，待試）：需要複製真人聲音、或要比 Kokoro 更自然的英文配音時；權重 CC BY 4.0 要標註；複查條件：下次要配英文旁白時並排試聽
- ACE-Step 1.5（T-60，待試）：需要長度剛好的配樂、又不想付費或擔心 Content ID 時
- Stable Audio 3（Small／Medium）（T-61，待查）：要快、長度要準的純音樂；複查條件：授權條件和本機版能否完全免費使用確認後再決定
- Mureka（T-62，未採用）：要中文歌、歌詞要唱清楚時；複查條件：需要中文歌時
- ElevenLabs Music v2.5（T-63，未採用）：要最快、長度準的配樂且有預算；複查條件：有付費預算時
- Openverse 音訊搜尋（T-65，待試）：要找音效或配樂時先用它
- earshot（T-67，待試）：Openverse 找不到想要的聲音、或要一整組風格統一的介面音效時

## 要注意

- 品牌 Logo 只用正式檔案或真實截圖（S4-02）
- 寫進規格前先看過素材畫面（S4-14）
- 大檔要用可續傳的方式下載，下載後驗證完整（S4-16）
- 免費音樂網站的曲子常登記 Content ID，上 YouTube 會被認領（S4-19，待試）
- 生圖模型畫出來的字常是錯的，畫面文字要另外疊上去（S4-21，待試）
- 原始影片不要先壓字幕（S4-01，待試）
- 不要：不要拿別人的影片當畫面（S4-09）
