# 7 算圖與混音

把定案的畫面和聲音算成母帶，並量過每一個規格。

**這一步要產出：** 母帶

## 要做

- [ ] **7.1 算圖**：一次只跑一個重的程序；先確認記憶體和磁碟空間
- [ ] **7.2 旁白與配樂**：有人說話時自動壓低音樂，音樂至少比人聲低 20 dB
  - 旁白出現時自動壓低音樂（S7-02）
- [ ] **7.3 音效**：畫面定案後才上，做成從 0 秒對齊的音效軌
  - 音效最後上，從 0 秒對齊（S7-03）
- [ ] **7.4 響度與規格**：響度約 −14 LUFS；量長度、fps、解析度

## 用什麼工具

- **ffmpeg-skill**（T-03）：剪、接、轉檔、音量、平台規格檢查（check.py）、縮圖表（look.py）
- **DeepFilterNet**（T-09）：視訊或手機錄音的底噪
- **HyperFrames**（T-19）：主要的影片引擎：用 HTML、CSS、GSAP 做畫面，逐格算成影片；snapshot 指令可以取任意時間點的定格
