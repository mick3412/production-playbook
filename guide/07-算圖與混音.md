# 7 算圖與混音

把定案的畫面和聲音算成母帶，並量過每一個規格。

**這一步要產出：** 母帶

## 要做

- [ ] **7.1 算圖**：一次只跑一個重的程序；先確認記憶體和磁碟空間
- [ ] **7.2 旁白與配樂**：有人說話時自動壓低音樂，音樂至少比人聲低 20 dB；換配樂就重量差距；混音不要跟著較短的音軌截斷，先寫新檔量過長度再取代母帶
  - 旁白出現時自動壓低音樂（S7-02）
  - 檢查：量切點和音效有沒有對上：時間量分軌，突跳量成品（S7-13，待試）
- [ ] **7.3 音效**：畫面定案後才上，做成從 0 秒對齊的音效軌
  - 幾種做法：(a) 照音效五原則配（S37）
  - 音效五原則：低沉圓潤、一個畫面最多 3 聲、同動作同聲音、人聲最大（S7-10，待試）
  - 音效對齊與混音：開始時間＝要對上的時刻－音效的對齊點（S7-11，待試）
  - 音效最後上，從 0 秒對齊（S7-03）
  - 檢查：音效要人聽過：戴耳機一次、手機喇叭一次（S7-09，待試）
- [ ] **7.4 響度與規格**：響度約 −14 LUFS；量長度、fps、解析度；跑黑格偵測
  - 檢查：算完跑黑格偵測；淡入的底色要和下一個畫面同色（S7-05）
  - 檢查：成片算完先跑一次 film_check：五項擋片、兩項提醒（S7-14）
  - 成品整體約 −14 LUFS、留 1–2 dB 餘裕、48 kHz（S7-12，待試）

## 用什麼工具

- **ffmpeg-skill**（T-03）：剪、接、轉檔、音量、平台規格檢查（check.py）、縮圖表（look.py）
- **DeepFilterNet**（T-09）：視訊或手機錄音的底噪
- **HyperFrames**（T-19）：主要的影片引擎：用 HTML、CSS、GSAP 做畫面，逐格算成影片；snapshot 指令可以取任意時間點的定格。同一套生態的技能：hyperframes-cli 管指令操作（建專案、預覽、算圖）；hyperframes-registry 有約 450 個現成轉場和字卡，第 5 階段先從這裡挑，不從零寫
- **javascript-animation-skills（含 sync-check）**（T-123）：要做 Canvas 逐格動畫＋程式合成配樂；或要量畫面切點和音效有沒有對上時
- **film_check.py（script2film 成片體檢）**（T-154）：每支成片算完、給人看或上傳之前

**這一步可以試的新工具：**
- Real SFX（Clipwing）（T-66，待試）：音效庫準備好、要把音效對到畫面時；複查條件：下一支動態圖文影片要上音效時
  - 測試方法：何時：下一支動態圖文影片｜怎麼做：同一支片，手動上音效一次、用 Real SFX 一次｜看什麼：音效是否落在正確的格、有沒有蓋過人聲、花的時間｜有效＝落點準、人聲清楚，時間省一半以上
- SFX Kit（wyzowl）（T-94，待試）：需要基本音效庫並讓 AI 自己選、對齊、混音時；複查條件：下一支要上音效的影片做 7.3 時
  - 測試方法：何時：下一支影片做 7.3｜怎麼做：讓 AI 只用 SFX Kit 配音效並照 sync.at 對齊｜看什麼：耳機和手機各聽一次（S7-09）是否對拍、是否蓋人聲｜有效＝不用手動挪就對拍

## 要注意

- 人聲和配樂的差距要實際量，換配樂就重量（S7-06）
- 混音不要讓輸出跟著較短的音軌截斷；先寫新檔再取代母帶（S7-07）
- 算圖和下載模型前先看磁碟空間（S7-04）
