# 2 腳本

內容決定一切；包裝再好，訊息不對觀眾也不會留下來。

**這一步要產出：** 核准稿

## 要做

- [ ] **2.1 六要素**：角色、受眾、主題、架構（前 3 秒、中段、結尾）、秒數、語氣一次給齊；改版時稿子已核准，2.1–2.3 可以略過，直接做 2.4
  - 腳本提示詞固定六要素（S2-01）
  - 口播稿要附語調備註（S2-10，待試）
  - 把喜歡的影片台詞交給 AI，整理出固定的敘事結構（S2-12，待試）
- [ ] **2.2 發散再收斂**：先比 3–5 個方向，選定後再展開成完整腳本
  - 開場一次寫多個，從不同角度切，再挑最好的三個（S2-07，待試）
  - 腳本先發散再收斂（S2-02）
- [ ] **2.3 具體化**：形容詞換成看得到的動作和數字
  - 抽象形容詞換成動作和感官細節（S2-03）
- [ ] **2.4 腳本關卡**：程式檢查、第二意見、審稿角色（學到什麼、專家挑錯、前 3 秒會不會停）；已核准的稿也要過。報告寫清每條意見怎麼處理，以及改稿後要重配音的鏡頭和總長變化
  - 檢查：配音前先過腳本關卡（S2-04）
  - 檢查：腳本裡的成果、數字和案例要真實並取得授權；發布前用自己的語氣改一次（S2-11，待試）
