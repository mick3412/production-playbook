# 8 交付與發佈

每個平台拿到對的檔案，素材標註齊全。

**這一步要產出：** 成品＋零件包

## 要做

- [ ] **8.1 平台版本**：依平台壓縮，加 faststart；檔案大小在上限內
  - 從長片切 Shorts：要能脫離原片獨立成立（S8-08，待試）
- [ ] **8.2 零件包**：需要時交 SRT、透明 PNG、推鏡片段、音效軌，全部從 0 秒起算
  - 可以只交零件，讓剪輯的人自己組（S8-01）
  - 剪輯的人要自己疊時，只交特效層：透明 ProRes 4444，或黑底 mp4（S8-05）
- [ ] **8.3 縮圖與封面**：做縮圖和封面，前 3 秒和封面要對得上
  - 幾種做法：(a) 標題和縮圖一組寫，用 yt-package 的 title.py 檢查（S41）
  - 標題和縮圖當成一組寫：縮圖不重複標題、最多 3 個字（S8-06，待試）
- [ ] **8.4 說明與標註**：說明欄附素材標註；上傳前人工確認
  - 檢查：對外發佈前一定有人核准（S8-02）
  - 標示點子來源並致謝（S8-03）
  - 檢查：YouTube 章節的硬規則：00:00 開始、至少 3 段、每段至少 10 秒（S8-07）

## 用什麼工具

- **ffmpeg-skill**（T-03）：剪、接、轉檔、音量、平台規格檢查（check.py）、縮圖表（look.py）
- **yutu**（T-25）：從命令列上傳 YouTube、改影片資訊和播放清單

**這一步可以試的新工具：**
- youtube-agent-skill（11 個 YouTube 技能）（T-74，待試）：寫 YouTube 腳本與開場、檢查標題縮圖、剪停頓清單、做章節、讀留存、切 Shorts、找同領域爆款時；複查條件：開始經營 YouTube 頻道時
  - 測試方法：何時：開始經營 YouTube 頻道｜怎麼做：用它寫一支的開場、標題縮圖、章節｜看什麼：點閱率、3 秒留存｜有效＝不低於手寫版本
- video-autopilot-kit（Hao0321）（T-89，未採用）：想參考短影音自動化流程（CapCut JSON、ffmpeg）時；複查條件：作者推出不綁特定工具的版本時
