# 3 分鏡與規格

在算任何畫面之前，把每一鏡做什麼、為什麼這樣做定下來；這是最便宜的修改時機。

**這一步要產出：** 分鏡規格

## 要做

- [ ] **3.1 分鏡表**：每一拍一列：時間、旁白原文、畫面、字幕、轉場；每個鏡頭只做一件事
  - 先分鏡，每個鏡頭只做一件事（S3-01）
  - 分鏡寫成表格，核准前不算圖（S3-02）
  - 設計和實作分開，中間停下來確認（S3-03）
- [ ] **3.2 意圖卡與母題**：寫視覺人格、情緒和畫面的對應、一個貫穿全片的視覺母題；每個圖示都要對應一項資訊，並定一套固定意義的顏色規則
  - 一支片一種風格，材質統一（S3-06）
  - 檢查：每個圖示都要對應一項資訊，顏色固定意義（S3-19）
- [ ] **3.3 動效詞彙**：用固定編號指定動效，規格寫成可量測的數字
  - 動效提示詞只寫動作、節奏、構圖、時長（S3-09，待試）
  - 效果規格寫成可量測的數字（S3-10，待試）
  - 交代一個特效用固定的四段：基本要求、對時間、去背、做法（S3-21，待試）
  - 讓使用者用看的挑，不用知道名稱（S3-12，待試）
- [ ] **3.4 時間閉合**：旁白片先配音（定稿前可用 TTS 暫配），再用「兩句之間停頓的中點」切鏡頭邊界；確認時間連續、沒有空洞，結尾等於總長
  - 鏡頭邊界取兩句之間停頓的中點（S3-17）
  - 從觀眾的角度去抓節奏（S3-14，待試）
- [ ] **3.5 風格定格**：新風格或新素材處理，先用正式流程出 3–5 張代表鏡頭的定格，核准後再算整支
  - 新風格先出 3–5 張定格核准，再算整支（S3-20）

## 用什麼工具

- **video-shotcraft**（T-20）：找鏡頭和動效的說法：124 張鏡頭配方卡和動態樣片
- **lemo-opuscar**（T-21）：需要現成的影片風格（59 種，含水彩、衛星簡報等）和它的風格提示詞
- **Motion Prompt**（T-36）：指定和移植動效：168 個有編號的動作，附規格和 Canvas 程式；photo 包只當生圖用語
- **video-script-builder（SURGE）**（T-38）：新格式或新風格開工前，先產一份分鏡規格當設計審查（意圖卡、母題、時間閉合、開放問題）

## 要注意

- 現成元件庫要用真資料試過才寫進規格（S3-15）
- 畫面上的標籤也算對外說法（S3-18）
- 不要：17 種特效不當日常模板（S3-07）

## 讓品質更好、更獨特

- ★★★ 用固定編號溝通動效（S3-11，待試）
- ★★ 單一 HTML 檔是最好分享的原型（S3-05，待試）
- ★★ 把資料對應成可以點的實體（S3-08，待試）
- ★★ 用一個視覺母題串起整支片（S3-16）
- ★★ 依內容類型挑動效：產品浮現、知識打字、數據翻轉、對比滑動、步驟前進（S3-22，待試）
