# 3 分鏡與規格

在算任何畫面之前，把每一鏡做什麼、為什麼這樣做定下來；這是最便宜的修改時機。

**這一步要產出：** 分鏡規格

## 要做

- [ ] **3.1 分鏡表**：先跑 `pb.py storyboard "需求"`：屬於既有系列就用系列格式（SF-），否則從推薦的 3 個分鏡模板（SB-）選一個；每一段用模板指定的版型代號（kits/storyboard/layouts.json，圖鑑 gallery/index.html），只能換成「可替換」清單裡的版型；`pb.py storyboard --use SB-xx --emit card.json` 出卡片草稿，只改欄位值、不寫座標；每一拍一列：時間、旁白原文、畫面、字幕、轉場；每個鏡頭只做一件事；兩層版面：字層（要讀的字）守安全區，畫面層（照片、背景、圖表延伸、特效）鋪滿全畫面，每一段寫明 visual 是什麼，不留純色空白；換版照換版規則（種類 ≤4／5、同版型連用 ≤3、字量固定、只在內容角色改變時換）；`pb.py card-check card.json` 通過才做動態分鏡給負責人看
  - 先分鏡，每個鏡頭只做一件事（S3-01）
  - 分鏡寫成表格，核准前不算圖（S3-02）
  - 設計和實作分開，中間停下來確認（S3-03）
  - 數字圖表：一張圖只講一件事，標題就是結論（S3-30，待試）
  - 分鏡每段指定版型代號，代理只填欄位，用 card-check 驗證（S3-32，待試）
  - 檢查：前 3 秒畫面的 8 點檢查：第一格就在動，3 秒內發生一件搶眼的事（S3-26，待試）
  - 照片影片先排出故事順序，再依情緒定每張秒數（S3-29，待試）
- [ ] **3.2 意圖卡與母題**：寫視覺人格、情緒和畫面的對應、一個貫穿全片的視覺母題；每個圖示都要對應一項資訊，並定一套固定意義的顏色規則
  - 一支片一種風格，材質統一（S3-06）
  - 檢查：每個圖示都要對應一項資訊，顏色固定意義（S3-19）
- [ ] **3.3 動效詞彙**：用固定編號指定動效，規格寫成可量測的數字；數值來源標出參考表的列
  - 交代一個特效用固定的四段：基本要求、對時間、去背、做法（S3-21）
  - 讓使用者用看的挑，不用知道名稱（S3-12，待試）
- [ ] **3.4 時間閉合**：旁白片先配音（定稿前可用 TTS 暫配），再用「兩句之間停頓的中點」切鏡頭邊界；確認時間連續、沒有空洞，結尾等於總長
  - 鏡頭邊界取兩句之間停頓的中點（S3-17）
  - 從觀眾的角度去抓節奏（S3-14，待試）
- [ ] **3.5 風格定格**：新風格或新素材處理，先用正式流程出 3–5 張代表鏡頭的定格，核准後再算整支
  - 新風格先出 3–5 張定格核准，再算整支（S3-20）

## 用什麼工具

- **video-shotcraft**（T-20）：找鏡頭和動效的說法：124 張鏡頭配方卡和動態樣片
- **lemo-opuscar**（T-21）：需要現成的影片風格（59 種，含水彩、衛星簡報等）和它的風格提示詞
- **Motion Prompt**（T-36）：指定和移植動效：168 個有編號的動作，附規格和 Canvas 程式；photo 包只當生圖用語
- **video-script-builder（SURGE）**（T-38）：新格式或新風格開工前，先產一份分鏡規格當設計審查（意圖卡、母題、時間閉合、開放問題）
- **huashu-art-motion（畫術動態）**（T-120）：要做解說片、財經圖表、動態文字、白板等「語法」明確的程式動畫，或想照一套分鏡表→算圖→QA→交付紅綠燈的流程做時

## 要注意

- 現成元件庫要用真資料試過才寫進規格（S3-15）
- 畫面上的標籤也算對外說法（S3-18）
- 不要：17 種特效不當日常模板（S3-07）

## 讓品質更好、更獨特

- ★★★ 用固定編號溝通動效（S3-11，待試）
- ★★★ 用一批動態樣本定風格：逐一標 Keep、Maybe、Drop（S3-23，待試）
- ★★ 單一 HTML 檔是最好分享的原型（S3-05，待試）
- ★★ 把資料對應成可以點的實體（S3-08，待試）
- ★★ 用一個視覺母題串起整支片（S3-16）
- ★★ 依內容類型挑動效：產品浮現、知識打字、數據翻轉、對比滑動、步驟前進（S3-22，待試）
- ★★ 實拍轉場：靠前後鏡對位，不靠特效軟體（S3-24，待試）
- ★★ 動效先提三個點子再做：logo、微互動、網站 hero、解說片、產品示範（S3-25，待試）
- ★★ 第一版普通時的追加句：固定色板、四層同動、一鏡到底、飛入開場、彈性大字（S3-27，待試）
- ★★ 建立自己的字幕風格：拆 3–5 支參考、兩種字型、一個強調色、對準聲音、做出深度、輕音效、存成規則（S3-28，待試）
- ★★ 動畫做成品牌的一套可重用元件，不要每支重做（S3-31，待試）
